# manuscript-figures

Figures, panels, and the result files behind them, as used in the kRISP-meR
manuscript. Panels are provided as vector **PDF** (used in LaTeX) and **PNG**
(preview). Scripts that generate these live in
[`scripts/figure-regen/`](../scripts/figure-regen).

## figure2-benchmarking/

Figure 2 — benchmarking vs CRISPOR and GuideScan2 across three genomes
(`human` GRCh38.p13, `mouse` GRCm39, `yeast` S288C). One subfolder per organism.

Per organism:
- `*_scatter.{pdf,png}` — read-based vs reference-based expected-cut concordance
- `*_bar.{pdf,png}` — off-target category breakdown + CFD retention overlay
- `*_violin.{pdf,png}` — global off-target burden per recommended guide
- `all_scores`, `ot_summary_*`, `cfd_score_summary_*` — the per-tool result
  tables the panels are plotted from (GuideScan2 uses the `*_filtered` files;
  yeast uses the `*_1_50` CFD summaries).

Generated by `scripts/figure-regen/plot_fig2_panels.py`.

## figure3-discordance/

Figure 3 — individual–reference genomic discordance (rice N22 vs japonica;
human CHM13 vs GRCh38). Assembled in LaTeX from atomic panels.

- `panels/hh_<org>_<class>.{pdf,png}` — head-to-head guide recommendation
  (accepted / rejected / not-generated), 3 tools.
- `panels/cfd_<org>_<class>.{pdf,png}` — assembly-CFD expected cuts for accepted
  guides.
- `panels/legend_{hh,cfd}.{pdf,png}` — shared legends.
- `data/asm_cfd_dist_{rice_n22,human_chm13,rice_japonica,human_grch38}.tsv` —
  per-guide assembly-CFD loads (cols: `cfd_cuts class group guide tool truth
  verdict`); the `n22`/`chm13` files back the panels, the `japonica`/`grch38`
  files are the reference-side counterparts.

Classes: `multiple_v_single` (duplicated in individual, single in reference —
should be rejected) and `present_v_absent` (present in individual, absent in
reference — should be recovered). Generated by
`scripts/figure-regen/panel_hh.py`, `panel_cfd.py`, `panel_legends.py`.

## table2-handpicked-genes/

Table 2 — representative guides in functionally characterized genes that a
reference-based tool accepts but that are duplicated in the individual (single
in the reference), which kRISP-meR rejects.

- `task1_human_grch38.tsv`, `task1_rice_n22.tsv` — full candidate lists with
  per-guide individual/reference copy number and assembly-CFD load.
- `task1_handpicked_examples_{human,rice}.txt` — the curated named-gene rows
  used in the manuscript table, with gene function and copy numbers.
- `task1_famous_genes_human.txt` — broader clinically-relevant gene context.

Generated by `scripts/fresh_n22/T1_famous_genes_{human,rice}.py`.

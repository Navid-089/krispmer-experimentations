DEFINITION OF A "HIT"
  A famous gene that CONTAINS a mis-accepted dangerous guide, where a
  mis-accepted dangerous guide is one that:
    (i)   has assembly-CFD off-target load >= 2  (duplicated / multi-cut in
          the individual's genome -- see Task 2c), AND
    (ii)  is ACCEPTED by a reference tool (CRISPOR MITspec>=50 or
          GuideScan2 spec>=0.2), AND
    (iii) is NOT accepted by kRISP-meR (Ecuts>1.5 -> kRISP-meR rejects).
  i.e. a guide a reference tool green-lights, that lands in an important
  gene, and that kRISP-meR correctly flags as dangerous.

  READING: e.g. GuideScan2 recommends a guide inside HLA-A/HLA-B with an
  expected off-target load of 5.4 genomic cuts; CRISPOR recommends a guide
  inside the beta-catenin oncogene CTNNB1 (2.75 cuts) and the coagulation
  gene PROS1 -- all guides duplicated/multi-cut in the individual, which
  kRISP-meR correctly rejects. Reference tools fail in different classes:
  GuideScan2 dominates the duplication classes (multiple_v_single,
  ref_multiple_v_single), CRISPOR the present_v_absent class.

    is small-n noise, ratio meaningless.

  HONEST READING:
   - The POOLED enrichment is NOT significant (ratio 0.84, p=0.86). Across
     all classes, mis-accepted guides are not, in aggregate, more likely to
     land in famous genes than kRISP-meR-safe guides. We do NOT claim a
     genome-wide "reference tools target important genes" effect.
   - ONE class is significantly enriched: ref_multiple_v_single -- 7/44
     mis-accepted guides in famous genes vs 0/45 kRISP-safe guides
     (p=0.0056). Here reference tools (GuideScan2) accept dangerous guides
     in famous genes (HLA-A/B, FCGR3A/B, SALL1) that kRISP-meR entirely
     avoids.
   - The result is therefore an EXISTENCE / case result, not an enrichment
     claim: reference tools DO recommend dangerous guides inside specific
     clinically important genes (the table above), and in the
     single-in-individual / multiple-in-reference class this is a
     statistically significant pattern.

WHY not a broad enrichment: duplicated (dangerous) guides concentrate in
multi-copy gene FAMILIES (HLA, FCGR3A/B, zinc-finger and olfactory-receptor
clusters). Some of these families are clinically important (HLA, FCGR3),
but most multi-copy loci are not "famous", so the overall famous-gene rate
is not elevated. The danger is real and lands on important genes in
specific, nameable cases -- which is what Task 1 set out to show.
